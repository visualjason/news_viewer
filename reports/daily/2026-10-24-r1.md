## 每日论文精读 · CVPR 2023｜OneFormer：用任务条件统一三类图像分割

原始发布：2023-06；分析日期：2026-10-24

历史论文专题：在同一数据集上只训练一个模型，通过任务 token 切换语义、实例和全景分割，用查询—文本对比学习帮助区分三种输出。

为什么重要：多任务共享不仅是合并输出头，还要让模型理解不同任务对同一区域的分组规则；适合研究减少模型维护与权重存储的路线。

建议：固定一个数据集和 backbone，先验证三种 task 输入，再按相同标注口径比较联合训练与单任务训练，单独记推理开销和每任务精度。

技术分析：图像经骨干和多尺度像素解码器；任务 token 初始化查询并参与解码，训练时由全景标注生成任务相关标签及类别文本。查询与文本对比损失辅助区分任务，推理去掉训练用文本 mapper，但保留任务输入。不是任意自由文本的开放词汇分割。

证据：正式 CVF 记录核实 CVPR 2023、2989–2998 页；正文方法/实验/结论与补充训练设置、消融、COCO 标注差异通过 PDF 文本完整相关章节读取。分析日期 2026-10-24，非本周新论文。

### 问题与创新 · §1、§3

语义分割合并同类区域，实例分割区分 thing 对象，全景分割同时表示 thing 与 stuff。OneFormer 每张训练图均匀采样一种任务，从同一套 panoptic 标注导出相应监督；一个模型服务同一数据集三任务，不是一份权重跨三个数据集通用，也不是不用标签训练。

### 方法流程 · §3.1–3.5

输入任务模板经映射得到 task token；重复为 N−1 个查询，经两层 transformer 从图像更新后拼接原 task token，形成 N 个对象查询。标注中的掩码类别转为文本列表，6 层文本编码器及可学习上下文产生文本查询；对称对象—文本对比损失与分类、BCE、Dice 损失联合训练。推理使用多尺度 masked attention 和分类/掩码预测，丢弃训练用文本 mapper。任务字符串只选择三类固定任务，不提供任意新类别。

### 主结果 · 表 1、2、3：同骨干不等于所有条件相同

ADE20K val，Swin-L/ImageNet-22K、640²、160k：OneFormer PQ/AP/单尺度 mIoU 为 49.8/35.9/57.0；对应单任务 Mask2Former 分别 48.7/34.9/56.1，但查询数分别 250 与 200/200/100，OneFormer 436G FLOPs，不能称计算量完全相同。Cityscapes 表 2：67.2/45.6/83.0，对应单任务 66.6/43.7/83.3；语义单尺度并未全面超越。COCO 表 3：OneFormer PQ 57.9 对全景基线 57.8，收益较小，不能把统一训练写成各指标显著胜出。

### 关键消融 · 表 4、5、7：看表格实际数值

Cityscapes Swin-L 表 4：去 task token，AP 45.6→43.3；去文本上下文，PQ 67.2→62.7；去任务引导初始化，PQ 67.2→65.8。表 5 无对比损失时 PQ/AP/mIoU 58.8/42.4/82.5，完整为 67.2/45.6/83.0。ADE20K 表 7 同 Swin-L、160k、batch16：联合 Mask2Former 为 48.7/33.7/56.2，OneFormer 为 49.8/35.9/57.0，即 PQ +1.1、AP +2.2、mIoU +0.8 个百分点；正文部分增量表述与表不一致，本分析按表计算，不照抄错数。

### 评估限制 · 表 3、8、补充 A/F

任务 token 确实改变输出侧重点，选错任务会损害其他指标。COCO 原始 instance 与 panoptic 标注存在不一致，表 3 的 AP 使用全景导出的实例标签，APinstance 才使用原实例标注：Swin-L OneFormer 49.0 vs 48.9，单任务 Mask2Former-Instance 49.1 vs 50.1；不可混合口径宣称胜出。论文“训练与存储可降至三分之一”是替代三份模型的结构性动机，不证明每任务推理加速三倍。闭集类别、重骨干、数据/任务采样偏差及泛化仍需实测。

### 复现条件与步骤 · 补充 A、作者 README

先固定正式表对应配置、预训练权重和数据分割。原仓库 Python3.8、PyTorch1.10.1/CUDA11.3、Detectron2 0.6，需编译相关算子；README 训练常用 8×A6000 48GB，部分大模型/COCO/896² 用 8×A100 80GB，不是轻量训练。建议先用已发布小模型跑三任务 demo，再对验证集以相应 task 评估 PQ/AP/mIoU，最后做任务 token/对比损失消融。补充 A 的 ADE20K crop 写512²，正文表1和发布配置有640²等设置，复现必须跟选定配置核对，不能混用；batch16、AdamW、ADE20K160k/Cityscapes90k/COCO100epoch。代码 MIT，不替代数据及权重许可；本次未安装运行。
